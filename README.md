# 뜨개노트

뜨개질 단수 카운터 겸 작품 기록 앱입니다. 두 가지 버전이 있어요.

- **아이폰 앱** (`iOS/`): SwiftUI로 만든 iOS 17 이상용 앱이에요. `iOS/TteugaeNote.xcodeproj`를 Xcode로 열어 실행해요.
- **웹 버전** (이 폴더): 빌드 없이 HTML, CSS, JS 파일만으로 돌아가요.

두 버전의 백업 파일(JSON) 형식이 같아서, 웹에서 내보낸 백업을 아이폰 앱으로 가져올 수 있어요.

## 글꼴 넣기 (처음 받았을 때 꼭 해 주세요)
글꼴은 메모먼트 꾹꾹체(`MemomentKkukkukk.ttf`)를 써요. 이 폰트는 **파일 재배포가 금지**라서 저장소에는 들어 있지 않아요.

1. [눈누 - 메모먼트 꾹꾹체](https://noonnu.cc/font_page/1663)에서 폰트를 내려받아요.
2. 파일 이름을 `MemomentKkukkukk.ttf`로 맞춰서 두 곳에 넣어요.
   - 이 폴더 맨 위 (웹 버전용)
   - `iOS/TteugaeNote/Fonts/` (아이폰 앱용)

폰트가 없어도 앱은 돌아가지만, 글자가 기본 글꼴로 보여요.

사용 범위 메모
- 폰트 파일 수정·재배포, 판매는 안 돼요.
- 웹 서비스에 폰트를 직접 넣어(임베딩) 공개하는 것도 제한돼요. 웹 버전을 공개 주소로 올리려면 다른 글꼴로 바꿔야 해요.
- 앱에 넣어 다른 사람에게 배포(앱스토어 등)하기 전에는 메모먼트에 사용 가능 여부를 확인하세요.

## 아이폰 앱 실행하기
1. Xcode를 설치하고 한 번 열어서 라이선스 동의와 iOS 구성요소 설치를 마쳐요.
2. `iOS/TteugaeNote.xcodeproj`를 열고 위쪽에서 시뮬레이터(예: iPhone 17)를 고른 뒤 ▶︎를 눌러요.
3. 내 아이폰에 설치하려면 아이폰을 케이블로 연결해요. 그다음 TteugaeNote 타깃 → Signing & Capabilities → Team에서 내 Apple 계정을 고르고 실행해요. 무료 계정은 7일마다 다시 설치해야 해요.
   - "번들 ID가 이미 사용 중"이라고 나오면 Bundle Identifier를 `app.tteugaenote.TteugaeNote`에서 나만의 이름으로 바꿔요.
4. 앱스토어에 올리려면 Apple Developer Program(연 $99)에 가입해야 해요.

`iOS/TteugaeNote` 폴더에 파일을 추가하면 Xcode 프로젝트에 자동으로 포함돼요.

| 파일 | 역할 |
| --- | --- |
| `TteugaeNoteApp.swift` | 앱 시작점 |
| `Models.swift` | 작품, 반복 알림, 보조 카운터 데이터 |
| `Store.swift` | 저장, 되돌리기, 단 세기 로직 |
| `ProjectListView.swift` | 작품 목록, 백업 |
| `CounterView.swift` | 카운터 화면 |
| `Sheets.swift` | 작품 편집, 카운터 설정, 설정 화면 |
| `Theme.swift` | 색, 진동, 공용 디자인 |
| `PatternViews.swift` | 도안(PDF·웹) 보면서 뜨기 화면, 줄 표시, 아래 작은 카운터 |
| `WobblyShape.swift` | 손으로 오린 듯 울퉁불퉁한 버튼 모양 |
| `AppFont.swift` | 메모먼트 꾹꾹체 등록·적용 |

### 아이폰 앱 도안 기능
- 작품 화면의 **도안** 칸에서 PDF를 불러오거나 웹 도안 링크를 붙일 수 있어요. 작품 하나에 도안 하나예요.
- **보면서 뜨기**를 누르면 위에는 도안이, 아래에는 −/+1단 카운터가 나와요. PDF는 마지막으로 보던 쪽을 기억해요.
- 위쪽 형광펜 버튼을 누르면 지금 뜨는 줄을 표시하는 막대가 나와요. 끌어서 옮길 수 있어요.
- 불러온 PDF는 앱 안(Documents/Patterns)에 복사돼요. 백업 파일(JSON)에는 PDF가 들어가지 않으니, 기기를 옮길 땐 PDF를 다시 불러와야 해요.
- 웹 도안은 https 주소만 열려요. http로 시작하면 https로 바꿔서 열어요.

## 웹 버전

### 기능
- **작품 관리**: 작품마다 이름, 실, 바늘, 목표 단수, 메모를 기록하고 진행 중/완성으로 나눠 봐요.
- **단수 카운터**: 큰 +1단 버튼, 되돌리기, 단 직접 입력을 지원하고 오늘 뜬 단수도 보여 줘요.
- **반복 알림**: "3단마다 양쪽 1코 늘리기 × 8회"처럼 정해 두면 해당 단에서 알려 줘요.
- **보조 카운터**: 무늬 반복이나 코 수를 따로 세요. ‘단과 연동’을 켜면 단과 함께 움직이고, 최대값을 넘으면 1로 돌아가요.
- **화면 켜두기·진동**: 설정에서 켜고 끌 수 있어요.
- **백업**: JSON 파일로 내보내고 가져와요. 데이터는 이 기기의 브라우저(localStorage)에만 저장돼요.
- **키보드**: 스페이스/↑로 +1단, ↓로 −1단, ⌘Z로 되돌리기.
- **도안 보면서 뜨기**: 작품 화면의 ‘도안’ 칸에서 PDF를 불러오거나 웹 링크를 붙여요. 위에는 도안이, 아래에는 −/+1단 카운터가 나와요.
  - PDF는 이 브라우저의 IndexedDB에 저장되고, 마지막으로 보던 쪽을 기억해요. 확대(100~300%)와 줄 표시 막대도 돼요.
  - PDF 보기에는 pdf.js(cdnjs, 3.11.174)를 써요. 처음 PDF를 열 때 한 번 받아 오고, 그 뒤로는 오프라인에서도 열려요.
  - 웹 도안은 화면 안에 띄워 보고, 사이트가 막아 두었으면 ‘새 탭에서 열기’로 열어요.
  - 백업 파일(JSON)에는 PDF가 들어가지 않아요. 다른 기기에서는 PDF를 다시 불러와야 해요.

### 실행
```bash
python3 -m http.server 5173
```
브라우저에서 http://localhost:5173 을 열면 돼요.

### 파일
- `index.html` 페이지 뼈대
- `styles.css` 디자인 (라이트/다크 모드)
